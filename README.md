# Pion Passé

Application web (PWA) pour progresser aux échecs : leçons, entraîneuse qui commente chaque coup, parties contre Stockfish.
Elle s'installe sur l'écran d'accueil d'un téléphone et fonctionne hors ligne.

Fichiers générés par `mobile/build.py` à partir des sources du site. Moteur : Stockfish 10 (GPL), chess.js (BSD).
